📄 Informes de temperatura

Para responsables e inspecciones sanitarias. No contiene datos técnicos de copia de seguridad.

Desde / Hasta se aplica a PDF, Excel y CSV. Elige cualquier fecha o un intervalo de varios meses.

📄 Exportar informe PDF

Informe listo para entregar: nombre claro del equipo, fecha y hora reales de medición, temperatura, responsable y foto integrada en cada registro.

📗 Exportar Excel organizado (.xlsx)

Selecciona «Desde / Hasta» arriba. Un solo mes: «Resumen Mensual» y «Registro Detallado». Varios meses: un resumen por mes y una hoja detallada para todas las fechas (máximo 36 meses). Días sin medición quedan vacíos y las observaciones se resaltan en amarillo.

📊 Exportar CSV (intercambio de datos)

Archivo de texto separado por «;», con indicación de separador para Excel. Para trabajar muchos días usa mejor el Excel .xlsx anterior.

Una medición no realizada nunca se mostrará con una temperatura u hora inventadas. El PDF no añade etiquetas de anotación posterior.
